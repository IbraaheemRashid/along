# Along — parked work

Updated 1 November 2026. These are possibilities, not promises or required day-one scope.

| Idea | Evidence needed before building |
|---|---|
| Optional weekly AI reflection over the user's own entries | People find deterministic recaps insufficient; grounded-summary evaluations show no invented facts, diagnosis or causal health claims. Explicit consent before records leave the device. |
| Reminder and home-screen widget | Users return for the core record; opt-in timing and neutral wording help without pressure. |
| More Pip accessories and scenes | Actual users value customisation enough to return or pay. Cumulative unlocks remain permanent; no penalties. |
| Cloud backup and multi-device sync | Users request recovery/sync; implement Better Auth and secure storage, deletion and export before claiming backup. |
| Shareable milestone or recap cards | Users want to share; default to excluding weights, notes and other sensitive details, with a preview and explicit action. |
| HealthKit import | Demonstrated demand for fewer manual entries; appropriate permission, provenance and duplicate handling. |
| A paid tier | Evidence of recurring value; decide free/paid boundary, price and real trial before Superwall integration and sandbox verification. Existing records and export must not become hostage to an upgrade. |
| Android and additional locales | Validated demand and retention on the first platform; no unsupported claim that the UK is unserved. |
| A nutrition module | Separate discovery and qualified review. The rejected pantry-led concept is not part of this backlog. |

Excluded from the current direction: dose recommendations, medication-level simulation, projected goal-weight dates, symptom treatment, automated calorie targets, diagnostic scoring, weight-loss competitions and rewards tied to eating less or losing weight. These are not “small additions” to the approved companion.

Along and Pip remain working names. Check store, domain and brand availability before public launch. No production release, account purchase or social campaign is implied by this list.
